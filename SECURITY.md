# Sicherheit

## Sicherheitslücke melden

Du hast eine Sicherheitslücke in Zeitfuchs gefunden? Bitte melde sie **vertraulich per E-Mail** an
**linalarsson.dev@gmail.com** (Betreff: „Zeitfuchs Sicherheit“) – **nicht** als öffentliches Issue,
damit niemand die Lücke ausnutzen kann, bevor sie behoben ist.

Hilfreich sind:

- die betroffene Version (in der App unter **Einstellungen → Informationen**),
- eine kurze Beschreibung und, wenn möglich, Schritte zum Nachstellen,
- was ein Angreifer damit erreichen könnte.

Ich bestätige den Eingang, prüfe die Meldung und halte dich auf dem Laufenden. Ist die Lücke behoben,
veröffentlichen wir sie gemeinsam – auf Wunsch mit deinem Namen als Finder:in.

## Updates

Korrekturen erscheinen als neue Version unter [Releases](https://github.com/LinaLarsson42/zeitfuchs-releases/releases).
Zeitfuchs sucht regelmäßig selbst nach Updates und weist im Programm darauf hin.
Ältere Versionen werden nicht separat korrigiert – bitte immer die neueste Version verwenden.

## Verwendete Komponenten

Jede Installation enthält im Programmordner eine Software-Stückliste (`sbom.cdx.json`, CycloneDX) und
die Lizenzhinweise aller verwendeten Komponenten (`THIRD-PARTY-NOTICES.txt`). Beides ist auch in der App
unter **Einstellungen → Lizenzen und Rechtliches** zu finden.

---

## Reporting a vulnerability (English)

Please report security issues **privately by e-mail** to **linalarsson.dev@gmail.com**
(subject “Zeitfuchs security”), not as a public issue. Fixes are shipped as new releases;
only the latest version is supported.
